    Pelagic · Nocturne

    Une mer qui répond

    Des milliers de dinoflagellés dérivent dans les courants. Comme dans la nature, ils s'allument quand l'eau est cisaillée : touchez-la, et la lumière vous suit.

    1. Main — glissez dans l'eau : un sillage lumineux s'y ouvre puis s'éteint.
    2. Tourbillon, Source, Récif — sculptez les courants. Molette ou inspecteur pour la force ; Maj+clic pour inverser.
    3. Balise — chante quand le plancton la traverse : la hauteur suit la profondeur, l'oreille suit le côté. Chaque balise a une voix : verre, cloche, pizzicato ou souffle.
    4. Marée — les notes se calent sur le tempo et la gamme choisis : le hasard des courants devient une musique.
    5. Composer — écrivez quatre mouvements (Éveil, Floraison, Dérive, Rémanence). À la lecture, l'océan se métamorphose de l'un à l'autre ; pendant ce temps, jouez avec la Main.
