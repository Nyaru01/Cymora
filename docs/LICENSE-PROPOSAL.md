# Licence proposée / Proposed licence

L’édition est gratuite pour les visiteurs : aucun paiement, compte, publicité ou clé API. Cela est distinct de l’autorisation de réutiliser le code.

Proposition : MIT pour les sources originales de cette collaboration, après choix explicite du titulaire des droits. Ce document est une proposition, pas un texte de licence adopté. Aucun fichier LICENSE n’annonce faussement que le titulaire a déjà accordé des droits. La publication publique du dépôt a été demandée ; une cession générale des droits n’a pas été formulée.

Inventaire de redistribution :

- JavaScript, HTML, CSS, SVG et compositions : écrits dans cette collaboration. Aucun paquet applicatif externe ni média téléchargé.
- Les polices sont des polices système référencées par nom, pas des fichiers de polices embarqués.
- Les idées de champs de courants et figures inspirées de Chladni ne sont pas présentées comme des données expérimentales ou un moteur physique calibré.
- Les actions GitHub et l’image Node sont des outils de construction ; leurs dépôts/images conservent leurs licences et ne sont pas incorporés aux scripts du navigateur.
- Les rapports et citations proviennent de cette expérience et de ses consignes. Les traductions sont identifiées. Les journaux privés et données du poste ne sont pas redistribués.

Aucun actif tiers à droit de redistribution incertain n’a été identifié. Ce relevé de provenance n’est pas une garantie juridique sur le statut d’une création assistée par IA. La proposition ne bloque ni la visite gratuite ni la publication autorisée des sources.

English: MIT is proposed for the collaboration’s original source after an explicit choice by the rights holder. This is not an adopted licence. The visitor experience remains free. The repository includes no bundled third-party fonts, media or application packages. Private journals and machine data are excluded.

Reference checked: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository . Without an adopted licence, a public repository should not be advertised as MIT-licensed.
