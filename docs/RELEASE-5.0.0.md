# QUATRE 5.0.0 — Public edition

Play: https://nyaru01.github.io/Duo/
Source: https://github.com/Nyaru01/Duo

Four works, no fifth artwork: the Garden of Currents, Nocturne, Résonance and INTERVALLE. French/English exhibition, landscape interactions, a sourced making-of and two independent final reports. Free visitor access, no account, analytics, microphone or API key.

Historical sources are preserved in public sanitised v1–v4 snapshots; original local history remains intact and private. See docs/PUBLIC-HISTORY.md for the mapping and redactions.

Validation: 78 automated tests; Windows/Linux Node 22/24 CI; browser journeys at the requested desktop/landscape CSS dimensions; real HTTPS JSON/PNG/SVG/audio exports. Captures and hardware/accessibility limits are documented in docs/G5-READINESS.md.

The site is live on GitHub Pages. Railway/Docker configuration is supplied, but no Railway service or billable resource was created and no Railway URL is claimed. MIT is proposed, not represented as adopted; see docs/LICENSE-PROPOSAL.md.
